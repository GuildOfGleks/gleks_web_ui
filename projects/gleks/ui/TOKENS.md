# `@guildofgleks/ui` — token reference

Every `--gog-*` custom property the library declares, grouped the way `styles/theme.css`
groups them. This is a reference to look things up in, not a document to read top to bottom —
the part worth reading is the three-layer model in the
[README's theming section](./README.md#theming), which explains what these layers mean and
which one to override for a given job.

The table below is **generated from `styles/theme.css`** by `scripts/generate-tokens.mjs` and
verified in CI by `npm run check:tokens`. Edit the stylesheet, not this file.

The same catalogue is available at runtime as `GOG_TOKEN_GROUPS` (typed by `GogTokenName`),
so a theme editor or docs page can enumerate the real tokens instead of copying this list.
