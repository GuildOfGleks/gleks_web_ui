gog-divider

Divider

A rule between two regions. Horizontal or vertical, three line styles, and an optional label that runs through the middle — projected as content, so it can be text, an icon or a tag.

With a label

Nothing projected renders one continuous line; anything projected splits it. The component has no hasLabel input — the stylesheet keys off whether the label element is empty.

Vertical

Stretches to a flex row's height, with --gog-divider-vertical-length as the floor when there is nothing to stretch to.

Inset

Indents the leading edge so the rule lines up with the text of a list whose rows start with an avatar or icon, instead of cutting across the whole row.

Theming

--gog-divider-color, --gog-divider-thickness and --gog-divider-spacing are instance-layer tokens: set them on one element to restyle just that divider.
