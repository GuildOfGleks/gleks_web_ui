gog-menu

Menu

A command menu opened from a button you own. [gogMenuTrigger] goes on your button, gogMenuItem on your items — so an item can carry an icon, a label and a shortcut hint without an input per piece. A closed menu renders nothing at all, and an open one renders into <body>, so nothing above it can clip it.

Playground

Open it, then use the keyboard: ↑/↓ move and step over the disabled item, Home/End jump to the ends, Enter runs one, Esc closes and puts focus back on the button.

Document actions

Last action: {{ lastAction() }} · closes: {{ closes() }} (gogClosed fires however the menu closed — item, Esc, Tab or a click outside).

Disabled items

An item is your own <button>, so you disable it the way you disable a button: the native disabled attribute — there is no input for it. A disabled item stays in the list (removing it would shift everything else under the pointer), the arrow keys step over it, and clicking it does nothing.

Statically disabled Bound to state

With Locked on, the second menu leaves only Open reachable — ↓ from it wraps back to itself instead of landing on a dead command.

A long menu scrolls itself

Past --gog-menu-max-height the panel scrolls with gog-scroll, the same scroller the rest of the library uses: thin, auto-hiding, and it keeps the wheel to itself when the list ends instead of handing it to the page. Arrowing past the last visible item scrolls it into view. The panel's height is the smallest of three — its content, that token, and the room between the trigger and the viewport edge; in 21.5.0 the token was overridden by the measurement and did nothing.

Row actions

What the component was built for: an icon button per row. The table wraps itself in a gog-scroll, and the panel still escapes it — that is why the menu always renders into <body> rather than offering a mode to get this wrong in.

Direction

direction is 'auto' by default: the panel drops down whenever it fits and flips up only when it cannot — unlike a select's listbox, which takes whichever side has more room. Force it with 'up' or 'down'.
