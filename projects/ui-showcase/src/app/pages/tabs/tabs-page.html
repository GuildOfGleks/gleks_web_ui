eager and lazy content

Content written straight inside gog-tab is built at once and only hidden while inactive, so it keeps what was typed into it. Content in an <ng-template gogTabContent> is built the first time its tab is shown, then kept. Type in the first tab, switch away and back: the text is still there, and the lazy tab reports itself built only once it has been shown.
