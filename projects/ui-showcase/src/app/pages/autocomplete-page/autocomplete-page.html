gog-autocomplete

Autocomplete

A text field that suggests options as you type. It shares its machinery with gog-select, but the trigger is a real <input>: focus stays in the field and the highlighted row is pointed at with aria-activedescendant, which is the ARIA combobox pattern.

Local filtering

Type two letters. Arrows highlight without moving focus, Enter picks, Escape restores the last selection.

value: {{ city() ?? '—' }}

Open on focus

On by default: focusing the field opens the panel immediately with every option, before minLength would otherwise have let anything through. Tab or click into each field below and compare.

Server-backed

gogSearch is debounced (300 ms by default) and [filterLocal]="false" stops the returned list being filtered a second time — the classic double-filtering bug, which silently drops rows the server matched on a field this component cannot see.

last query: “{{ lastQuery() }}” · results: {{ remoteResults().length }} · loading: {{ remoteLoading() }}

Load more on scroll

gogLoadMore fires when the panel is scrolled to the end of the list — the signal to fetch and append another page, instead of handing 200 rows over up front. Open the panel and scroll to the bottom to load the next 20.

loaded: {{ loadedContacts().length }} / 200

Your own DTO

Dot-path accessors read a nested object, [optionValue]="null" hands the object itself back, and a gogDropdownOption template decorates the row. Vira is suspended and cannot be picked.

Free text

[forceSelection]="false" keeps what you typed on blur — for a create-as-you-type flow, where the text itself is the answer. Read it from gogSearch rather than from value.
