DialogConfig: modal, closable, draggable, role, title

modal, closable and draggable are all on by default. Off, modal drops the dimmed backdrop, the focus trap and the body scroll lock; closable removes the close button, Escape and the backdrop press, leaving the content's own buttons; draggable keeps the header but stops it moving. Without a title the header holds only the close button.

your own component

A rename form: data pre-fills it, Save resolves afterClosed with an object, Cancel and the close button with undefined. Its select needs [appendToBody]="true": the dialog's body is a scroller, and a list rendered inside it is clipped under the header. In <body> it stacks above the dialog on the --gog-dropdown-z the panel raises. Escape closes the open list first, and the dialog only on the next press.

width and maxWidth

Both are CSS lengths written onto the panel; maxWidth wins when the two disagree. Unset, the panel is as wide as its content, up to 90vw.

long content

The body scrolls inside the panel, capped by --gog-dialog-body-max-height, and the header stays put.

closeIconName and closeIconTemplate

stacking, and closeAll

Open one, then another from inside it. Escape closes only the top one; Close all resolves every open dialog's afterClosed with the value it is given.

dismissing

Escape, the close button, and a press that both starts and ends on the backdrop — a drag that starts inside the panel and is released outside it does not close. All three resolve afterClosed with undefined. Tab and Shift+Tab cycle inside a modal dialog; a non-modal one lets focus leave, and the page behind it stays usable — a press there reaches the page and leaves the dialog open.
