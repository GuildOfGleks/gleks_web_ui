gog-select

Select

A dropdown select with label, chevron icon slot, error state, size variants, disabled options, placement control, a body-portaled panel, and `ControlValueAccessor` support. Once open, Arrow Up/Down move between options, Home/End jump to the first/last, and Escape closes.

Sizes

Full width

Full width of its container by default (see every field above). [fullWidth]="false" shrinks the trigger to fit its selected label instead — useful for a compact field alongside one that should keep growing.

States

The error above is entirely computed by this page — `gog-select` just renders whatever `errorMessage` it's given, for as long as it's non-empty.

Reactive Forms — automatic error timing

With errorDisplay="auto" and a [formControl], the field decides for itself when to show the error — once the control has been touched and is invalid — instead of the page computing that timing. Click the field, then click away without choosing anything.

Custom chevron & label-less field

chevronTemplate swaps the trigger's icon. ariaLabel names a field that has no visible label at all.

Append to body

Useful inside scrollable or overflow-clipped containers — the panel escapes into `document.body` instead of getting clipped.

Custom panel size

dropdownWidth and dropdownMaxHeight take any CSS length and override the trigger-derived size — useful when the panel needs to be narrower/wider or shorter than the field itself. Applies only with appendToBody; the list below has 20 options, capped to 160px so it scrolls internally.

Opening near the bottom of the page

Scroll down to reach this one. With appendToBody, the panel flips upward automatically and is positioned against the trigger itself — not the whole field — so it never covers the label above it or the control below it.
