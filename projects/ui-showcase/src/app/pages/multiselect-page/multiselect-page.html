gog-multiselect

Multiselect

A checkbox-driven multiselect dropdown with select-all/clear controls, size variants, disabled options, placement control, and an optional body-portaled panel. Once open, Arrow Up/Down move between options, Home/End jump to the first/last, and Escape closes.

States

The error above is entirely computed by this page — `gog-multiselect` just renders whatever `errorMessage` it's given, for as long as it's non-empty.

Full width

Full width of its container by default (see every field above). [fullWidth]="false" shrinks the trigger to fit its selected summary instead.

Float label

floatLabel makes the label rest inside the trigger like a placeholder, then float up on focus or once something's selected — 'in' stays inside the border, 'on' floats to the border line, 'over' floats fully above it. floatLabelShowPlaceholder reveals placeholder once floated (hidden the whole time otherwise). Both are also settable app-wide via GOG_CONFIG.floatLabel — see the Global config page.

Reactive Forms — automatic error timing

Same idea as gog-select: errorDisplay="auto" shows the error once the attached [formControl] has been touched and is invalid, with no manual error computation on this page's side.

Custom chevron & label-less field

A gogDropdownChevron template swaps the trigger's icon. ariaLabel names a field that has no visible label at all.

Custom option row & clear icon

A gogDropdownOption template replaces each row entirely — here a colored dot before the label. A gogMultiselectClearIcon template replaces the trigger's clear-all glyph. [clearable]="false" on the last field drops the clear button even once something's selected.

Append to body

Useful inside scrollable or overflow-clipped containers — the panel escapes into `document.body` instead of getting clipped.

"Select all" / "Clear" position

controlsPosition puts the control row above or below the option list — either way it's pinned in place with position: sticky, so it stays visible instead of scrolling away with a long option list.

Custom panel size

dropdownWidth and dropdownMaxHeight take any CSS length and override the trigger-derived size. Applies only with appendToBody; the list below has 20 options, capped to 160px so it scrolls internally.

Opening near the bottom of the page

Scroll down to reach this one. With appendToBody, the panel flips upward automatically and is positioned against the trigger itself — not the whole field — so it never covers the label above it or the control below it.
