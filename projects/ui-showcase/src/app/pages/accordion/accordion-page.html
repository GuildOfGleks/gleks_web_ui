loading × showChevron

While loading is on, each row is a placeholder: one per item when the items are known, skeletonCount of them when items is still empty. The chevron gets a placeholder too, so the row that arrives has the silhouette of the one that waited.

gogAccordionContent

The body is an <ng-template gogAccordionContent let-item>, rendered once per item with the item as $implicit. An item is any object with an id and a title, so it can carry whatever the body needs. Every body on this page is one.

gogAccordionHeader

Replaces the title with any markup, with $implicit (the item) and open in its context. It renders inside the header button, so it must not hold another control — a button inside a button is invalid and unreachable.

gogAccordionChevron

Replaces the chevron, with the same context. The default chevron rotates by itself; a template owns its own open and closed look, so nothing rotates underneath it. It is aria-hidden either way — aria-expanded on the header is what says open.
