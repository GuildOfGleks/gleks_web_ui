gog-tabs / gog-tab

Tabs

A tablist over projected <gog-tab> children. Each tab declares its own label, icon and disabled state, so a tab is written in exactly one place — and the header row is built from that.

Basic

One tab stop for the whole tablist; the arrows move and activate, Home/End jump to the first and last enabled tab. Archive is disabled and gets skipped.

Eager content keeps its state

Content written directly inside a tab renders immediately and is only hidden while inactive — type below, switch tabs, and come back.

Switching here does not destroy the field next door.

Lazy content

An <ng-template gogTabContent> is built on first activation and kept alive afterwards. Which behaviour you get is decided by whether the template is there — there is no lazy input to keep in sync.
