Ripple

A pointer-position wash that grows from where you pressed. A directive, so it goes on any element you already have — no wrapper, no layout change. Built from scratch: there is no CDK in this library.

It does not clip a badge

The reason the ripple is not simply overflow: hidden on the host. gogBadge pins its badge outside the host's box with negative insets, so a host that clips its overflow clips the badge with it. The wash lives in its own layer that clips itself instead — press this and the badge stays whole.

rippleCentred and rippleDisabled

Keyboard activation is always centred — Enter and Space carry no coordinates — so tab to the first button and hold a key to see what centred looks like. rippleCentred makes the pointer behave the same way.

Suppressed where a press means nothing

A host that is disabled or aria-disabled="true" gets no ripple without you having to say so twice — answering a press the control will not act on is worse than staying still. Reduced motion suppresses it outright rather than shortening it: turn on your OS's “reduce motion” setting and none of these produce anything at all.

The library's own components

You do not add gogRipple to a gog-* component — each one already owns the element that paints its surface, so it wires its own. What you do is turn it on: provideGogConfig({ ripple: { enabled: true } }) once, and every surface below answers a press. Off by default, so adding the ripple to the library changed the look of nothing.

Everything in this box — and only in this box — is inside a scoped provideGogConfig, which is why the rest of the showcase is still still. Each component also takes a ripple input that wins over the app-wide setting in both directions.

Put it on the element that paints the surface

The layer takes its corner radius from its host through border-radius: inherit, which is exact and free — and is also the one thing to know. On a wrapper whose child paints the rounded background, the layer inherits the wrapper's radius, so the wash squares off at the corners. Both buttons below are ripple-wrapped; only the second one has the directive on the element that actually has the radius.

Library components never make a consumer think about this: each one opts its own inner element in. The rule only applies to markup you wrote yourself.

Theming

Five tokens, and the colour is currentColor by default, so the wash reads as the surface's own foreground on a filled surface and on a ghost one alike. Every one of them is an ordinary inherited custom property — set it on the element, or on anything above it.
