the region takes its size from its host

gog-scroll scrolls whatever does not fit the box its host is given: set a height (or a max-height) on the element, as every region on this page does with one class. Leave the host's display alone: it is a flex column, and that is what carries the height down to the viewport — display: block on it lets the content spill out. Content is projected as-is.
