size × variant

runic is the default and the library's own; ring is the plain one. custom projects your markup into the same size box, so it scales like the other two — the third column projects a pulsing square. Under prefers-reduced-motion the built-ins stop moving and stay drawn; a custom one is yours to stop.

--gog-spinner-color

The spinner draws in the accent colour. On a surface where the accent does not read — a danger banner, a filled button — set --gog-spinner-color on it or an ancestor.

gog-spinner-overlay

The content stays rendered underneath, so nothing jumps when loading ends. The scrim stops the pointer; it does not stop the keyboard — Tab still reaches the button below while it is covered. Disable what must not be pressed while it loads; the gap is filed.

overlay — the whole viewport

[overlay]="true" on gog-spinner itself covers the viewport, for a load that blocks the whole app. "The viewport" holds only while no ancestor creates a containing block — a transform, filter or contain above it retargets the overlay to that element, so render it near the app's root.

host attributes

Read from the live DOM. The spinner is role="progressbar" with no value — the pattern for "working, no idea how long" — named by ariaLabel. Name it for what is loading when more than one thing can be. ariaLabel="" makes it decorative. Inside a loading gog-button it is aria-hidden, because the button already says it is busy. Until 21.15.0 none of this was rendered: ariaLabel was accepted and dropped, and every spinner was missing from the accessibility tree.

A spinner that appears announces nothing by itself — it is not a live region, and it should not be one: a region that says "Loading" every time a request starts is noise.
