clickable is on by default

Every chip is a button and a tab stop unless it says otherwise. A chip that only shows a value — a tag in a list, an applied filter whose only action is its remove button — should set [clickable]="false", or a keyboard user tabs through a row of buttons that do nothing. For a status label with a colour, gog-tag is the component.
