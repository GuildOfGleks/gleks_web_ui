size × state

size is row density. Loading replaces the body with a spinner and marks the host aria-busy; an empty value renders one row with a dash. Hover on a sortable header is live.

gogColumnBody and gogColumnHeader

A cell template gets the row as $implicit and row, its index on the page, and the resolved value; a header template gets the column's header text and field, so it can decorate rather than replace. A field can be a dot-path.

row numbers, column borders, emptyPlaceholder, widths

showRowNumbers is on by default. showColumnBorders draws the vertical rules. A missing value renders as emptyPlaceholder — "Accordion" has no owner. width, minWidth and maxWidth size a column.

[fullWidth]="false"

The table sizes to its columns instead of its container.

pagination, total and their positions

pageSize above 0 pages the rows; showTotal adds a count, placed by totalPosition, and paginatorPosition places the pages.

stickyHeader with maxHeight

maxHeight gives the table its own vertical scroll, and only then can stickyHeader pin the header to it. Scroll the table.

sorting

Click a sortable header, or Tab to it and press Enter: ascending, descending, then unsorted. Text sorts by locale, numeric-aware. "Component" here has a comparator that sorts by length instead.

selection

selectionMode="multiple" adds a checkbox column with a select-all for the current page; 'single' keeps at most one. The selection is always an array, two-way through [(selection)].

selectOnRowClick and gogRowClick

With selectOnRowClick the whole row toggles, so the checkbox column can go; the rows become focusable and Enter or Space toggles them. gogRowClick fires for every press that reaches a row, with the row and its index on the page.

[lazy]="true" — a server owns sort and pages

The table renders value as given and asks totalRecords how many pages there are; gogSortChange, gogPageChange and pageSizeChange are the refetch signals. This one talks to a fake 137-row endpoint with a 350 ms delay. dataKey="id" keeps a selection across pages and refetches.

[virtualize]="true"

Renders only the rows in view — here 10 000, every seventh one taller, which is why the window measures rows as they render rather than assuming a height. It needs maxHeight and fullWidth, and switches itself off with a warning without them. Give maxHeight in px, % or vh: in rem the window silently renders every row — filed.
