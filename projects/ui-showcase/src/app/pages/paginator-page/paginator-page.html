gog-paginator

Paginator

Page-number controls, extracted from gog-table into a standalone component. It only needs a page count — no notion of rows or columns — so it drops into a table, an accordion, a plain list, or anything else you page through.

Basic usage

page is a two-way bindable model — [(page)]="mySignal" — and totalPages is the only other thing the paginator needs to know. By default it shows a fixed, centered window of page buttons that slides as you navigate — click through and watch page 1 drop off once the current page moves past the middle of the window.

Flexible page-range settings

rangeMode="window" (the default) keeps exactly visiblePages buttons on screen, centered on the current page, with no ellipsis unless showFirstPage/showLastPage ask for one. rangeMode="ellipsis" is the original behavior — first and last page always pinned, siblingCount pages kept around the current one — preserved as an opt-in for consumers already built around that look, like gog-table itself.

Full width

Full width of its container by default — the dashed outline below is the container, not the paginator, so you can see the component's own box claims the full row even though the buttons don't fill it. [fullWidth]="false" shrinks the box to fit the buttons instead.

fullWidth: true (default)

fullWidth: false

Disabled

disabled freezes every control — useful while the page it navigates is itself loading.
