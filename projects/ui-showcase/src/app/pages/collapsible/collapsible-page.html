an overlay inside the content

Open the select: its list is cut off at the bottom of the content. The content keeps overflow: hidden while open — the same rule that makes a capped panel above scroll — so a dropdown, menu or tooltip rendered inside an open collapsible is clipped. This is a defect, filed; the demo stays so the fix has a case to show.
