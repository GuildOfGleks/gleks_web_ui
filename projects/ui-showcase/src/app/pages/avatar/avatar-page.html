fallback × size

The third row's src is a URL that does not exist. The page is server-rendered, so that picture fails before the app hydrates and its error event has fired before any listener exists: the initials there are the component reading the image's own state on its first browser render. A bare <img> would show the broken-image glyph.

circle for a person, rounded for an organisation or a product. The picture takes the avatar's own corner, so the two can never disagree.

initials from name

with a badge

Status is gogBadge on the avatar — there is no status input. On a circle the badge anchors where the circle crosses its box's diagonal rather than in the empty corner, and because an image's children are not read, the count reaches a screen reader as the avatar's description (aria-describedby).

swapping src after a failure

Press the button: the URL alternates between one that fails and one that loads. Each new src starts over, so a picture that failed once does not stay failed.

max

max counts the +N avatar, so the row's width is known from max alone: seven people at max="5" draw four and +3. The ones not drawn leave the accessibility tree; the +N is named for them ("3 more", GOG_CONFIG.labels.moreAvatars).

size, and a long tail

The group's size reaches every avatar through --gog-avatar-size, so the row is one size whatever each avatar says. Past 99 the +N draws 99+, the way gogBadge caps its count; its name keeps the exact number.
