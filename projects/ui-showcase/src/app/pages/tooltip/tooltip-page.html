'auto' goes above and flips when there is no room; the others are fixed sides, and still flip rather than leave the viewport. The bubble caps its width against the viewport too.

text, and a template

gogTooltip takes a string, or a TemplateRef for richer content. A long string wraps at the bubble's cap. Keep it a hint: a tooltip cannot hold a control, since nothing in it can be reached by keyboard.

gogTooltipClass

The bubble lives in <body>, so a --gog-tooltip-* token set on an ancestor never reaches it. A class on the bubble itself does; the showcase's global stylesheet defines the one used here.

delays

The show delay keeps tooltips from flashing as the pointer crosses a toolbar; the hide delay is what lets the pointer travel from the trigger onto the bubble.

hoverable, dismissible, and gogTooltipDisabled

Move the pointer from the trigger onto the bubble: it stays. Press Escape while it shows: it goes, and the trigger keeps focus. gogTooltipDisabled turns one off without removing the directive.
