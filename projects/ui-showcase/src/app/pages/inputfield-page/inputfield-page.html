gog-inputfield

Inputfield

A labeled text field with leading/trailing icon slots (either decorative or clickable), error message support, size variants, and `ControlValueAccessor` integration.

Playground

The email error is computed by this page from the current value — `gog-inputfield` only renders whatever `errorMessage` it's given (`errorDisplay="manual"`, the default).

Password visibility toggle

Built in: any field with type="password" automatically gets a trailing eye / eye-off button that swaps the native input type between password and text — no extra wiring needed.

Clickable icon action

A trailing icon can act as a button via iconEndFn — combined here with a decorative leading icon.

Sizes & disabled

Full width

Full width of its container by default (see the fields above, each filling its own field-grid cell). [fullWidth]="false" shrinks a field to fit its own content instead — useful when a short field (like a ZIP code) shouldn't stretch to match its neighbors.

Float label

floatLabel makes the label rest inside the field like a placeholder, then float up on focus or once there's a value — 'in' stays inside the border, 'on' floats to the border line, 'over' floats fully above it. floatLabelShowPlaceholder reveals the field's own placeholder once floated (it's hidden the whole time otherwise). Both are also settable app-wide via GOG_CONFIG.floatLabel — see the Global config page.

The leading/trailing icon slots line up correctly at every variant — the label and the field share the same icon-aware inset instead of the label falling back to the unindented default.

Float label with a password field

type="password" always renders the built-in show/hide toggle as a trailing icon — the same icon-inset code path as iconEnd above. Side by side with floatLabel off and on, to confirm the eye toggle lines up correctly either way.

Reactive forms — automatic error timing

With errorDisplay="auto" and a [formControl], the field decides for itself when to show the error — once the control has been touched and is invalid — instead of the page computing that timing. Click the field, type less than 3 characters, then click away.
