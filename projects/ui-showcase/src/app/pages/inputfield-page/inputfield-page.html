gog-inputfield

Inputfield

A labeled text field with leading/trailing icon slots (either decorative or clickable), error message support, size variants, and `ControlValueAccessor` integration.

Playground

The email error is computed by this page from the current value — `gog-inputfield` only renders whatever `errorMessage` it's given.

Clickable icon action

A trailing icon can act as a button via `iconEndFn`, e.g. a visibility toggle.
