gog-icon

Icon

Renders an SVG by name — one of the 20 built-ins, or any icon the app has registered with provideGogIcons — or projects an arbitrary TemplateRef in its place. Sized via --gog-icon-size, colored via currentColor — most of the other components on this site already use it internally (tag, chip, tooltip, inputfield addons, …); this page shows it standalone.

Built-in set

Every GogBuiltinIconName — the closed set the package ships. GogIconName is the open one an input takes: these plus anything registered. Color follows the surrounding text.

@for (name of iconNames; track name) {
{{ name }}
}

Your own icons

provideGogIcons({{ '{' }} cart: '<svg…>' {{ '}' }}) in app.config.ts registers icons by name — after that they behave exactly like a built-in, including in every component that takes an icon name rather than a template. This app registers three (see custom-icons.ts); the three rows below are three unrelated components asking for the same registered glyph, with no <ng-template> anywhere.

The third one shares its name with a built-in: a registration wins over the library's own glyph, which is how you swap the whole set's checkmark or chevrons for yours without touching a single component. Compare copy here with the one in the built-in gallery above.

An unknown name renders nothing and warns in the console in dev mode — an icon is decoration, and taking the app down over a typo in a glyph name would be the worse failure.

Size & color

--gog-icon-size is the only sizing hook; color always inherits from the element's own color.

Custom template

When template is set it wins over name entirely — the built-in SVG set is never consulted. Useful for a one-off glyph that doesn't belong in the shared catalog.

Decorative vs. meaningful

ariaHidden defaults to true — the icon is assumed decorative (redundant with adjacent text, like the labelled buttons below) and stays invisible to screen readers. Set it to false and give a title when the icon is the label, as in an icon-only button.

icon-only, ariaHidden=false + title — announced on its own
Copy next to visible text, default ariaHidden=true — announced once, via the text
