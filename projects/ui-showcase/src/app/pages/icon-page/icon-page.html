gog-icon

Icon

Renders one of the library's built-in SVGs by name, or projects an arbitrary TemplateRef in its place. Sized via --gog-icon-size, colored via currentColor — most of the other components on this site already use it internally (tag, chip, tooltip, inputfield addons, …); this page shows it standalone.

Built-in set

Every GogIconName value. Color follows the surrounding text.

@for (name of iconNames; track name) {
{{ name }}
}

Size & color

--gog-icon-size is the only sizing hook; color always inherits from the element's own color.

Custom template

When template is set it wins over name entirely — the built-in SVG set is never consulted. Useful for a one-off glyph that doesn't belong in the shared catalog.

Decorative vs. meaningful

ariaHidden defaults to true — the icon is assumed decorative (redundant with adjacent text, like the labelled buttons below) and stays invisible to screen readers. Set it to false and give a title when the icon is the label, as in an icon-only button.

icon-only, ariaHidden=false + title — announced on its own
Copy next to visible text, default ariaHidden=true — announced once, via the text
