pattern × value written in

A literal appears only once a slot after it is filled — +38 (050, never +38 (050) — except a leading run, which comes with the first character. Every cell is live: type into one, paste into one, delete across a literal.

the pattern language

In the pattern Accepts
0 a digit
a a letter, in any script
* a letter or a digit
\x the literal x — \0 is a zero that is not a slot
anything else itself, a literal inserted as the user types

gogMaskTokens adds slot characters or overrides the three above. An array of patterns is a value whose length varies: the first pattern with room for what was typed is used, and the value is complete when it fills any of them exactly.

on any input — or gog-inputfield's own mask

The directive's selector is input[gogMask], so it works on a native input you own, or one inside a component that is not this library's. gog-inputfield runs the same engine through its own mask, maskTokens and maskValue inputs — see the Inputfield page. It cannot take the directive on its inner input, because the field is already that input's form accessor.

Each pattern is digits only, so the field asks for the numeric keyboard on its own. Backspace just after a space deletes the digit before it, not the space — otherwise the engine would put the space straight back and the caret would be stuck.
