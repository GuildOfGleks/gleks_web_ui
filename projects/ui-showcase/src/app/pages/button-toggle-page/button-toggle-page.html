gog-button-toggle-group

Button toggle group

A row of buttons where one — or, with multiple, several — can be picked. Takes your own objects through optionLabel / optionValue / optionDisabled, the same accessors gog-select uses.

Single choice

A radio group to assistive tech: role="radiogroup" with aria-checked, one tab stop, and the arrow keys both move and select — which is what a radio group does. Map is disabled and gets skipped.

value: {{ view() }}

Multiple choice

A different widget, not a cosmetic switch: role="group" with aria-pressed, arrows move only, and Space toggles.
