gog-textarea

Textarea

A labeled multi-line text field with error message support, size variants, adjustable initial row count, and `ControlValueAccessor` integration — the textarea counterpart to `gog-inputfield`.

Playground

The notes error is computed by this page from the current value — `gog-textarea` only renders whatever `errorMessage` it's given (`errorDisplay="manual"`, the default).

Rows

rows sets the native rows attribute, controlling the field's initial height before the user resizes it.

Sizes & disabled

Full width

Full width of its container by default. [fullWidth]="false" shrinks the field to fit its content instead, matching every other field-style control in the library.

Float label

floatLabel makes the label rest inside the field like a placeholder, then float up on focus or once there's a value — 'in' stays inside the border, 'on' floats to the border line, 'over' floats fully above it. floatLabelShowPlaceholder reveals the field's own placeholder once floated (it's hidden the whole time otherwise). Both are also settable app-wide via GOG_CONFIG.floatLabel — see the Global config page.

Reactive forms — automatic error timing

With errorDisplay="auto" and a [formControl], the field decides for itself when to show the error — once the control has been touched and is invalid — instead of the page computing that timing. Click the field, type less than 10 characters, then click away.
