gog-datepicker / gog-calendar

Datepicker

A date field with a calendar panel — single date, range, and an optional clock. Native Date, no date library: Intl supplies month and weekday names, and the display format is a token pattern so what is written can always be read back.

Single date

value: {{ show(date()) }}

Range

Two months side by side is what makes a range picker usable. The panel stays open between the two clicks, and hovering previews what the second click will produce.

value: {{ showRange(range()) }}

With a time

The panel stays open after a day is picked, so the clock is reachable without reopening. Changing the time never moves the day.

value: {{ showDateTime(withTime()) }}

Typing

Typed text is parsed against format. A half-typed date leaves the value alone rather than firing a stream of nulls at an attached form, and an impossible date (31.02.2026) is rejected instead of silently rolling over to 3 March.

Locales

Month and weekday names come from Intl, and the first day of the week from the locale unless you override it. Both are also settable app-wide via GOG_CONFIG.datepicker.

Footer buttons

Two separate actions, deliberately not one. Today selects today's date — the view follows, because the selection is what the calendar opens on. This month only moves the view back and leaves the selection alone, for browsing far from today without committing to anything. One button doing both is what made the control ambiguous: after paging away, the same label reads as "take me back" to one person and "set it to today" to another.

value: {{ show(footerDate()) }} · the last one has min in the future, so Today is disabled rather than silently doing nothing.

Inline

No field, no panel — literally gog-calendar, which is exported on its own for exactly this.

value: {{ show(inlineDate()) }}
