Write a registered SVG the way the built-ins are written — a viewBox, currentColor, no width or height — and it sizes and colours like them. The markup goes in through bypassSecurityTrustHtml, because Angular's sanitizer strips SVG: register markup you wrote, never a string built from user input.

host attributes

Read from the live DOM. [ariaHidden]="false" turns the icon into a named image: role="img", named by title or else by the icon's name — and a name like more-vertical is rarely what a person should hear, so set the title. Before 21.15.0 the role was missing, and the name sat on an element that Chrome exposes as a generic and screen readers skip. Written as a plain attribute, title="Warning" also lands on the host as the HTML title — hover the second row's icon and the browser shows its tooltip, on a decorative icon as much as on a named one.

which one to use

Beside text — the default, and nothing to do. Carrying meaning no text repeats, like a status mark in a table cell — [ariaHidden]="false" with a title. The only content of a button — leave the icon decorative and name the button (ariaLabel on gog-button): the name then belongs to the thing that is pressed, and a screen reader says it once.
