content × badgeVariant

badgeVariant takes the four status names gog-tag takes and defaults to danger, the colour of a count someone should look at. A number over badgeMax (99) prints as 99+; a word is left alone, since capping only means something for a count. badgeDot drops the text for "something changed here" with no number to give.

hosts

A directive, so it decorates what is already there rather than wrapping it: a gog-button, a native button, a link styled with gogButton, or any element — the host only gains position: relative to hold the badge. An inline element needs to be made a box (inline-flex below) so the corner is its corner.

zero, and badgeHidden

Step the count down to zero: the badge leaves the DOM rather than showing "0", and null and an empty string do the same. badgeHidden is the other way to take it away — the count underneath is kept, so it comes back as it was. Neither changes the host's size, because the badge was never part of its layout.

the focusable element's attributes

Read from the live DOM. On a focusable host the badge is inside it, so its text — or badgeAriaLabel, which replaces the number — is part of the host's name and no attribute appears. gog-button is the other case: its host is a wrapper and the real <button> is inside, so the badge describes that button through aria-describedby and it reads "Inbox, button, 12 unread". Until 21.15.0 the count sat beside that button, and Tab said only "Inbox, button".

@switch (state) { @case ('button gogBadge="12"') { } @case ('button gogBadge="12" badgeAriaLabel="12 unread"') { } @case ('gog-button gogBadge="12" — its inner button') { Inbox } @case ('gog-button gogBadge="12" badgeAriaLabel="12 unread" — its inner button') { Inbox } @case ('a gogButton gogBadge="12"') { Inbox } }

what to put in badgeAriaLabel, and where not to put a badge

Without it a screen reader hears the bare number, "Inbox 12", which is usually enough. Give the wording when the number alone is ambiguous — "12 unread", "3 failed checks" — and keep it in step with the count, as the Behaviour demo does. A dot has no text, so a dot that matters needs badgeAriaLabel or it says nothing. And put the badge on the control, not on its icon: a gog-icon is aria-hidden by default, and everything appended inside it is hidden with it.
