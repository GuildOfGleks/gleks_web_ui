one menu for every row, resolved from what was clicked

Right-click a file — or focus one and press the ContextMenu key or Shift+F10. One listener on the list, [gogContextMenuResolve], works out which file was clicked; between the rows it returns null and the browser's own menu opens instead. The items are ordinary gogMenuItem buttons, arrowed between and dismissed exactly as in gog-menu.
