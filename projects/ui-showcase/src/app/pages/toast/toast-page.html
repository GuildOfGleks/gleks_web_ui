the stack, and maxVisiblePerPosition

Each corner is its own stack, oldest in front. Only the front toast counts down; the ones behind wait with a full bar and fan out on hover. Past maxVisiblePerPosition (5) the rest queue out of sight and are not announced until they are shown.

actions, show() and dismiss()

An action's onClick gets the toast; pressing one does not close it, so an Undo calls dismiss(toast.id) itself. show() and the four shorthands return that id.

dedupeKey

A show() whose dedupeKey matches a toast still open replaces it in place — new message, timer restarted, announced again — instead of stacking another. Unset, the key is derived from the message, type, icon, position and action labels, so the same toast fired twice is one toast; this button changes its message each time, so it needs an explicit key.
