Two built-in presets ship with gog-spinner — pick one via the variant input. runic is the original branded spinner; ring is a plain tapered ring for a more neutral look.

Custom variant

Need your own look entirely? Set variant="custom" and project any markup — it inherits the size wrapper, overlay behaviour, and picks up --gog-spinner-color like the built-in presets.

One spinner for the whole app — GOG_CONFIG.spinner.component

variant="custom" restyles one spinner. Most of the spinners an app shows are ones it never writes: gog-button draws one while loading, gog-autocomplete while it searches, gog-table in place of its rows, and gog-spinner-overlay over a whole region — none of them take a spinner input. Pass a component to GOG_CONFIG and every one of them is yours. It is rendered inside the library's own size wrapper, so the sizing, role="status" and the accessible name survive; only the visual is yours.

Watch the overlay tile. Until 21.10.0 it forwarded a variant of its own, defaulting to runic, which the spinner inside read as an instance overruling the config — so this panel would have shown the house loader in four places and the built-in in the fifth, on a key documented as reaching all of them. The provider here is scoped to this panel; a real app calls provideGogConfig once in app.config.ts.

Full-screen overlay

gog-spinner itself can render as a fixed, viewport-covering overlay via overlay="true" — distinct from gog-spinner-overlay, which only covers its own content.
