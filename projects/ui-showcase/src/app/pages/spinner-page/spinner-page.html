Variants

Two built-in presets ship with gog-spinner — pick one via the variant input. runic is the original branded spinner; ring is a plain tapered ring for a more neutral look.

Custom variant

Need your own look entirely? Set variant="custom" and project any markup — it inherits the size wrapper, overlay behaviour, and picks up --gog-spinner-color like the built-in presets.
