gog-multiselect

Multiselect

A checkbox-driven multiselect dropdown with optional select-all/clear controls, five sizes, disabled options, placement control, and a body-portaled panel. Once open, Arrow Up/Down move between options, Home/End jump to the first/last, and Escape closes.

Examples

Sizes

Five steps, also settable app-wide through GOG_CONFIG.control.size.

States

Empty, holding a selection, disabled and with an error. The clear button is there without asking: unlike every other control, clearable defaults to true here, because it shipped a clear button before the input existed — [clearable]="false" drops it. Disabled dims the whole field as one piece .

A long selection collapses to +N

The trigger shows what fits on one line and a count for the rest; the labels are measured with canvas.measureText rather than by rendering candidates. The count is aria-hidden, and the whole selection is listed in the trigger's tooltip, bound only while something is hidden. Shrink the window to watch it re-measure: the space changes when the container resizes, which Angular never renders for, so a ResizeObserver drives it.

Width

A field fills its container by default — the dashed box here. With [fullWidth]="false" the trigger sizes to its own summary, so an empty selection collapses it; minWidth is the floor under that.

Icon slots, and no visible label

gogDropdownChevron replaces the chevron. The library turns only its own; a custom one gets let-open and draws the state itself — before 21.15.0 a custom chevron turned 180° here and never in a select. gogMultiselectClearIcon replaces the glyph in the clear button, not the button, so its name is still clearAriaLabel. ariaLabel names a field with no label.

Your own objects

optionLabel, optionValue and optionDisabled take a property path — dot-paths included — or a function. [optionValue]="null" makes the value an array of the option objects themselves. A gogDropdownOption template replaces one row; the per-option checkbox stays, as the control's affordance. [gogDropdownOptionTypeOf] types the option.

A disabled option

optionDisabled defaults to the disabled property, so an option carrying it needs no binding. The row stays in the list, is announced as disabled, and neither the pointer nor "Select all" picks it up.

Filtering

filter puts a search box in the panel — worth it past about seven options. The default matcher is a case-insensitive substring of the label; filterMatch swaps in any predicate. The query resets when the panel closes. The search box has square corners, and that is the concentric answer: inset from the panel edge by exactly the panel's radius, its corner sits on the centre of the panel's corner arc, the one shape that keeps the gap constant. Override --gog-multiselect-panel-radius and it reshapes to match.

"Select all" and "Clear"

showControls adds the row; controlsPosition puts it above or below the list, and it is sticky there, so it stays reachable in a long list. "Select all" acts on the options currently visible — type 1 into the filter and it selects the eleven that match, not all twenty. Disabled options are never picked up.

The panel — appendToBody

The panel renders inline by default and is clipped by any scrolling or overflow: hidden ancestor; open the first two — only the appended one survives its box. dropdownWidth and dropdownMaxHeight take any CSS length and apply only while the panel is appended.

Virtualized options — virtualize

Both fields hold 10 000 options: the windowed one keeps about twenty rows in the DOM, the eager one builds all 10 000 to show six. Off by default and never switched on at a row count — Ctrl+F finds only rendered rows, :last-child matches the last rendered one. aria-setsize keeps the real count. "Select all" means the whole filtered list, not the rendered window, so it selects all 10 000. Set it app-wide with GOG_CONFIG.dropdown.virtualize.

Float label

'none' keeps the label above the field; 'in', 'on' and 'over' rest it inside the trigger until focus or a selection moves it clear — each shown empty, then with a selection. floatLabelShowPlaceholder brings the placeholder back under the floated label.

Reactive forms

With errorDisplay="auto" the error shows once the control is touched and invalid — open the panel and close it without choosing. Validators.required treats the empty array as missing, which makes "at least one" the default meaning of a required multiselect. The trigger carries aria-invalid and points aria-describedby at the message .

App-wide defaults — GOG_CONFIG

control.size, the dropdown keys and the two control labels set the defaults for every field under the provider; an instance's own input still wins. Open the third field: the filter is at the bottom and the controls read "All of them" / "None". In an app the provider goes in app.config.ts — see Global Configuration.

Accessibility

The trigger is a role="combobox" that owns a multi-select role="listbox"; each row is a role="option" carrying aria-selected. Disabled is reported as aria-disabled on the trigger.

  • Keyboard — on the trigger, Enter or Space opens the panel and ↓ / ↑ open it on the first or last option. In the list the arrows move and skip disabled options, Home/End jump to the ends, Enter or Space toggles the focused option, Esc closes and returns focus to the trigger, and Tab closes and moves on. The options are one tab stop. Inside a dialog, Escape closes the list first and the dialog on the next press .
  • Name — label, or ariaLabel. The +N count is hidden from assistive tech; the full selection is in the trigger's description.
  • Error — aria-invalid and an aria-describedby pointing at the message.
