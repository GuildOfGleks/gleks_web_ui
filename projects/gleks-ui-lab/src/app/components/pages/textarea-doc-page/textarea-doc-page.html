gog-textarea

Text Area

A multi-line counterpart to gog-inputfield, sharing its five sizes, its tokens, error handling and full ControlValueAccessor support, with a themed resize grip of its own.

Examples

Sizes

Five steps, the same scale as gog-inputfield; also settable app-wide through GOG_CONFIG.control.size.

States

Default, disabled, readonly and with an error. Focus is a pseudo-class, so it is not shown here — tab into any field. readonly blocks edits while the value stays focusable, selectable and submitted with the form.

Error timing you own

With the default errorDisplay="manual" the message shows for as long as errorMessage is non-empty — the page decides when. Type fewer than ten characters.

Rows

rows is the native attribute: the field's initial height, before anyone drags the grip.

Resize

resize takes the native CSS values — 'vertical' (the default), 'horizontal', 'both', or 'none' for no grip. The grip is the library's own, so it follows the theme instead of showing a browser's corner triangle; the drag underneath it is the browser's. Drag a corner to watch the grip follow. Set it app-wide with GOG_CONFIG.textarea.resize.

Clearable

The clear button shows only while there is something to clear, so it adds no permanent chrome. It sits in the field's top end corner and steps clear of the scrollbar once the content overflows — the second field. A readonly field has nothing to clear and shows no button.

Width

Fields fill their container by default — the dashed box here. [fullWidth]="false" shrinks the field to its content instead.

Native attributes

name, maxlength, minlength and spellcheck go straight onto the <textarea>. maxlength stops typing at 72; minlength is the browser's own constraint, not an Angular validator — pair it with Validators.minLength in a form. spellcheck unset leaves the browser's default.

Float label

'none' keeps the label above the field; 'in', 'on' and 'over' rest it on the first line and float it clear on focus or a value — each shown empty, then filled. floatLabelShowPlaceholder brings the placeholder back under the floated label.

Reactive forms

With errorDisplay="auto" the error shows once the control is touched and invalid — tab in and out of the empty field — instead of the page computing the timing.

App-wide defaults — GOG_CONFIG

control.size, control.clearable, floatLabel.variant and textarea.resize set the defaults for every field under the provider; an instance's own input still wins. In an app the provider goes in app.config.ts — see Global Configuration.

Accessibility

A native <textarea>: role, value, editing and the keyboard all come from the platform.

  • Name — the label, through its for. There is no ariaLabel input; a field without a visible label should get one, or a floating one.
  • Keyboard — Tab enters and leaves the field, Enter makes a new line rather than submitting the form. The clear button is its own tab stop and is named by clearAriaLabel, or GOG_CONFIG.labels.clear.
  • State — disabled and readonly are the native attributes, so a screen reader announces them as such.
  • Error — aria-invalid on the textarea and an aria-describedby pointing at the message, which is a role="alert".

Styling Tokens

gog-textarea paints with the same --gog-input-* tokens as gog-inputfield — there's no separate token set to learn. Override any of them — on a single instance, a subtree, or a theme — to restyle it. See the Theming guide for the full token-layering model.
