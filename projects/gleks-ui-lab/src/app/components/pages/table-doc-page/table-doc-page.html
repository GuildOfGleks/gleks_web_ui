gog-table

Table

A sortable, paginated data table with custom cell/header templates, size variants, sticky headers, loading and empty states, and built-in row numbers.

Overview

Import TableComponent and Column, then declare one <column> per field as content — gog-table reads them via contentChildren, so the columns live in your template, not a config array.

Custom cell & header templates

Any column can swap its default text rendering for a projected <ng-template template="field"> — here the status column renders a gog-tag instead of raw text, and its header gets custom markup too.

Status {{ $any(row).status }}

Pagination & total count

pageSize turns on pagination (0 disables it), rendered with the same gog-paginator documented separately. showTotal adds a row-count label; totalPosition places it left, right, or opposite the paginator (the default).

Sticky header

stickyHeader sticks the header row to the top of the nearest scrolling ancestor — here that's a wrapper capped at 260px, so scroll inside the table to see it.

Missing values

A cell whose field is null/undefined falls back to emptyPlaceholder — "-" by default, overridable per table.

Default placeholder

emptyPlaceholder="N/A"

Full width

Full width of its container by default (see every table above). [fullWidth]="false" shrinks the table to fit its columns instead — useful for a narrow, two-column table that shouldn't stretch to fill a wide page.

Loading state

Shows a spinner in place of rows while loading is true.

Toggle loading

Empty state

An empty value array renders a built-in placeholder row.

{{ showEmpty() ? 'Restore rows' : 'Clear rows' }}
