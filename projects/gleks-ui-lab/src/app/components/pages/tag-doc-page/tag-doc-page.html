gog-tag

Tag

An informational status label with four semantic variants, two shapes, five sizes, and width that follows the text without wrapping by default.

Overview

Import the component and drop it into a template.

Basic usage:

Examples

Four variants cover the common status meanings. Five size steps, from xsm to slg. Square-ish rounded corners, or a fully rounded pill. Project an <ng-template gogTagIcon> to replace the leading icon. It takes priority over iconName. This replaces the iconTemplate input, which is deprecated in 21.3.0 and removed in 21.5.0. Both work meanwhile, and the projected slot wins when a call site has both — which is what lets a codebase migrate one tag at a time. Fits its text with no wrapping by default (see every tag above). fullWidth stretches it to fill its container instead — wrapped here in a narrower box to show it.
