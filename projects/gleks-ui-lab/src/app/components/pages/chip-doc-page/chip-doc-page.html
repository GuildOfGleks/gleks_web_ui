gog-chip

Chip

A compact, clickable label with five sizes, two shapes, and optional avatar, icon, and remove affordances.

Overview

Import the component and drop it into a template.

Basic usage — a clickable chip with projected content:

Examples

Five size steps, from xsm to slg. Square-ish rounded corners, or a fully rounded pill. removable adds a trailing (×) button that emits gogRemove and stops the click from also reaching gogClick. clickable="false" drops the role="button", tab stop, and pointer cursor — for a chip that's a static label, not a control. Blocks click and keyboard activation, and hides the remove button even if removable is set. Shown when avatarUrl is not set. Renders independently of iconName — if both are set, the avatar and icon both render. Stretches to fill its container; wrapped here in a narrower box to show it.
