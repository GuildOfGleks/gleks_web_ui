gog-datepicker

Datepicker

A date field with a calendar panel: a single date, a range, and an optional clock. Native Date, no date library and no adapter abstraction — the package keeps its zero runtime dependencies.

Overview

Import the component and drop it into a template.

Import it from @guildofgleks/ui/datepicker, together with gog-calendar. The root package has not exported it since 21.14.0 — in 21.13.0 it still did, deprecated — and that is what lets a datepicker used only behind a lazy route keep its own code out of your app's initial bundle. What it imports from the root does not move: the icons it draws belong to the root package, and load wherever your first page already loads it. Measured on a fresh app with the table, datepicker, calendar and dialog behind one lazy route: the initial bundle went from 101.2 kB to 88.2 kB, and 27 kB of those components' root dependencies stayed in it.

Examples

Sizes

Five steps, also settable app-wide through GOG_CONFIG.control.size.

States

Empty, holding a value, disabled, and with an error. The calendar button is not optional — it is the one affordance that says this field is more than a text box, and it is what openCalendarLabel names.

Clearable

clearable is off by default and puts a second button beside the calendar one. Unlike gog-autocomplete it watches the value, not the text: a half-typed date that has not parsed yet leaves it hidden, because nothing committed is there to clear.

Width

A field fills its container by default — the dashed box here. With [fullWidth]="false" it falls back to a text input's own width; there is no minWidth, since there is no selected label for it to collapse onto.

No visible label

ariaLabel names a field with no label, and the panel takes the same name. placeholder is empty by default, which is why stating the format in it is worth doing.

A single date

[(value)] holds a Date; valueChange fires on every change, a picked day, typed text that parses, and a clear.

Range

selectionMode="range" makes the value a {{ '{' }} start, end {{ '}' }} pair, and two months side by side is what makes picking one usable. The panel stays open between the two presses and hovering previews the second; only the second press completes the selection and closes it. The half-picked range is a valueChange of its own, because a form bound to the field has to see what the user currently means — gogDateSelect is the event that waits for both ends.

Bounds and disabled dates

min and max bound the range; disabledDates takes a predicate, because an array cannot express "weekends" or "public holidays" without materialising every date first. A disabled day is a disabled button: announced, and neither the pointer nor Enter takes it. defaultMonth decides which month opens when nothing is selected.

Time

showTime adds a clock under the grid, and format gains HH:mm on its own. A field with a time does not close when a day is picked — the clock would be unreachable — so the panel waits for a press outside or Esc. If you set format yourself, include the time in it, or the field prints a time it cannot read back.

Typing — one pattern, both directions

format is a token pattern — yyyy, MM, dd, HH, hh, mm, ss, a — used to print and to parse, so whatever the field shows can be typed back. A draft that does not parse leaves the value alone rather than clearing it, and blur snaps the text back. 31.02.2026 is rejected rather than becoming 3 March. A range field is read-only whatever allowTextInput says: there is no pattern for two dates and a dash.

Locale

Month and weekday names come from Intl, so a locale is all a translated calendar needs. The first day of the week follows the locale unless firstDayOfWeek overrides it. The date format is deliberately not derived from the locale: it is the pattern in format.

The labels

The field's own openCalendarLabel and clearAriaLabel, plus the nine strings of the calendar inside it — the footer buttons, the four navigation arrows and the three time fields — so one field can be named in another language than the app's config says. Open it: the arrows read German.

The panel — appendToBody

The panel is a role="dialog" holding the calendar. It renders inline by default and is clipped by any scrolling or overflow: hidden ancestor; open both — only the appended one survives its box. It follows the field on scroll, and --gog-datepicker-panel-width is the knob if the panel needs a width.

Inline

inline drops the field and the panel and renders the calendar permanently — literally gog-calendar. The inputs that describe the field (label, clearable, floatLabel, appendToBody) have nothing to act on.

Float label

'none' keeps the label above the field; 'in', 'on' and 'over' rest it inside until focus or a value moves it clear — each shown empty, then with a value. floatLabelShowPlaceholder shows the format once the label has floated.

Reactive forms

A ControlValueAccessor. With errorDisplay="auto" the error appears once the control is touched and invalid — closing the panel marks it touched, as blurring the field does. Open the panel and close it without choosing.

App-wide defaults — GOG_CONFIG

This is the component that earns the config most: an app states its locale, first day of week and date format once, and every field agrees. Open the first field — the week starts on Sunday though de-DE would choose Monday: firstDayOfWeek overrides the locale, one layer down. An instance's own input still wins. In an app the provider goes in app.config.ts — see Global Configuration.

Accessibility

The trigger is a text input that owns a dialog: aria-haspopup="dialog" rather than a combobox, because what opens is a grid of days and not a list of options. The grid follows the ARIA grid pattern — see Calendar.

  • Keyboard — from the field, ↓ or Enter opens the panel. Esc closes it from anywhere inside — the calendar button and the day grid included — and returns focus to the field. In the grid the arrows move by a day and a week, Home/End to the ends of the week, PageUp/PageDown change the month and with Shift the year, and Enter or Space picks. The 42 day cells are one tab stop.
  • Fixed in 21.15.0 — Escape closed the panel only from the text input, and the arrows moved the highlight while the focus ring, and a screen reader, stayed on the day they had left.
  • Name — label or ariaLabel; the calendar button is named by openCalendarLabel, the clear button by clearAriaLabel.
  • Error — errorMessage sets aria-invalid and links the message with aria-describedby.
