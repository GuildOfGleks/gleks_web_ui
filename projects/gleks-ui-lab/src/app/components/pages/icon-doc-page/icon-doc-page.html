gog-icon

Icon

A thin wrapper around the library's built-in SVG set — or a slot for your own template. Small on its own, but every other component that needs an icon (button, checkbox, dialog, input field...) renders through it.

Overview

Import the component and drop it into a template.

Sizing

There is no size input — icons are sized purely through the --gog-icon-size CSS custom property, settable per-instance or globally through a theme.

Meaningful icon

Icons are aria-hidden by default, since they're almost always paired with a visible text label. For a standalone icon that carries meaning on its own, set ariaHidden to false and supply title.

Custom template

template replaces the built-in SVG entirely — the same mechanism other components use for their own icon override inputs (e.g. checkbox's checkIconTemplate).
