gog-breadcrumbs

Breadcrumbs

Where the current page sits, as a trail of your own links. Every part of a correct trail is invisible — the named landmark, the list, aria-current="page" on the last item, separators a screen reader does not read — so nothing on screen says when a hand-built one is missing them. The links stay yours: routerLink, href and anything else on them keep working.

Overview

Mark each item with the structural *gogBreadcrumb directive. The last item is the current page — usually a <span>, since it does not link anywhere:

Examples

Sizes

Five text steps. The parents are links in the muted colour, the current page is the text colour and semibold; hover a link for the underline, Tab to it for the ring.

Collapsing a long trail

Past maxItems the middle becomes a … button; itemsBefore and itemsAfter say how many stay either side (one and two by default — the current page and its parent). Press the … from the keyboard: the button is removed by its own press, so focus moves to the first link it revealed rather than falling to <body>. A trail that would hide nothing does not collapse.

separatorIcon

Any icon name, built-in or registered with provideGogIcons. It is drawn, not written, so it never reaches a screen reader.

Right to left

The separator points from a parent to its child, which is leftwards under dir="rtl". Nothing to set — the trail reads the direction it is in.

A narrow container

A long trail wraps between items rather than overflowing; maxItems is the answer when it should stay on one line.

Accessibility

A trail a screen reader can use is mostly structure that nothing on screen shows.

  • Landmark — a <nav> named "Breadcrumb", from ariaLabel or GOG_CONFIG.labels.breadcrumbs, so it appears in a screen reader's landmark list beside the main navigation.
  • List — an ordered list, one <li> per item, so the reader hears how many levels deep the page is.
  • Current page — the trail sets aria-current="page" on your last element, and moves it when the last item changes. Leave it out of the link: a link to the page you are on is a dead end.
  • Separators — aria-hidden; "chevron" between every word is noise.
  • The … button — a real button named "Show full path" (GOG_CONFIG.labels.showBreadcrumbs), and focus moves to what it revealed.
